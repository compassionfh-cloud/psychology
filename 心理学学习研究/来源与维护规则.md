# 来源与维护规则

## 精选目录

首批书目由人工按代表作者、原著身份和公开来源编选。优先来源：Project Gutenberg、York University 心理学史档案、OpenStax、BCcampus、作者网站、Wellcome Collection 和出版社。

每条记录保留作者、原作年份、实际链接版本、资源类型、来源、访问性质和授权限制。这里的分类为学习导航，允许一部著作与多个方向有关；不宣称囊括所有心理学取向。

## 自动搜寻

每周更新任务已在 Codex 中建立，时间为周日 10:00（北京时间）。任务会检索、核验、更新书目，并报告有价值的新增资料或运行问题；仓库脚本也可随时手动运行。

`scripts/search_books.py` 从 `search-config.json` 的代表作者与关键词查询公开书目 API。每次每条查询最多收录 32 条 Gutenberg 结果或 8 条 Open Library 结果，不进行无限翻页。请求之间至少间隔 1 秒，单请求超时 25 秒。

Gutendex 是第三方 Gutenberg 书目接口；权利与版本仍需回到 Gutenberg 核实。Open Library 是书目发现服务；`ebook_access`、预览或借阅状态不构成文件转载授权。

所有新结果进入 `检索报告/`，等待人工核验。查询失败会在报告中保留具体状态，已有候选不会因为部分来源失败而消失。全部查询失败时脚本返回非零退出码。

人工审核顺序：核对作者身份 → 核对原著和具体版次 → 核对来源及全文范围 → 核对授权 → 决定是否进入精选目录。不要将销量、搜索排名或书名含“心理”视为学术权威的证据。

## 更新目录

编辑 `catalog.json` 后运行 `python3 scripts/build_catalog.py`。该脚本重建分类页与总览，不写入网络搜索结果。阅读笔记与路线独立保存。

参考接口：[Open Library Search API](https://openlibrary.org/dev/docs/api/search)、[Gutendex](https://gutendex.com/)。
