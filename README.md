## 自动搜寻

已按用户选择建立每周更新任务：每周日 10:00（北京时间）检索、核验并维护本仓库。

使用 Python 3.10 或以上版本，无需安装依赖或申请 API 密钥：

```bash
python3 scripts/search_books.py
```

从 Gutendex（Project Gutenberg 书目）和 Open Library 搜寻代表作者，去重并保存到 `心理学学习研究/检索报告/`。脚本只生成待核验候选；网站超时或拒绝访问会写入报告，不会伪装成搜索成功。

## 获取电子书

书目中可直接打开官方阅读/下载入口。已核对的 Gutenberg 图书也可按编号保存为 EPUB：

```bash
python3 scripts/download_books.py --id james-briefer --id freud-dreams
```

文件保存在被 Git 忽略的 `.local/ebooks/`，并生成来源与 SHA-256 清单。脚本会检查 EPUB 容器，下载失败不会被记录为成功。其他仍受版权保护的著作通过出版社购买、机构访问或图书馆借阅。

## 维护

人工核验后编辑 `心理学学习研究/catalog.json`，再运行：

```bash
python3 scripts/build_catalog.py
python3 -m unittest discover -s tests
```

自动检索与人工精选目录分开保存。维护方式与范围见[来源与维护规则](心理学学习研究/来源与维护规则.md)。
